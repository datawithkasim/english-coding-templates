# 🔺 001 — 피라미드 문제

> 📦 **보관된 코스입니다.** 이 코스의 내용은 [000 — 빌더 기초](../000-builder-basics) 의 **레슨 11~15**(사각형 바닥 · 첫 피라미드 · 거꾸로 피라미드 · 피라미드 변형 · 다이아몬드)로 합쳐졌습니다. 새로 시작하는 학생은 빌더 기초 하나만 따라가시면 됩니다. 아래 자료는 이미 이 코스를 진행 중인 학생을 위해 그대로 둡니다.

---

마인크래프트 에이전트로 한 줄짜리 길에서 출발해 다이아몬드 구조물까지 코드로 직접 쌓아 올립니다.

반복문과 변수, 중첩 반복문을 차근차근 익히고, 마지막에는 함수로 나만의 명령어를 만드는 **두 번째 코스**입니다.

> ⏱️ 정해진 기간은 없습니다. 아래 순서대로, 아이가 준비되면 다음 레슨으로 넘어갑니다.
