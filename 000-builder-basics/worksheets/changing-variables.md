## 1 · Predict 🔮

A variable can **change while the code runs**. `height = height + 1` means: take what `height` holds, add 1, put it back.

Read each set of steps. Write what you think will happen.

```
height = 1
repeat 4 times:
    place block down
    move up by height
    move forward
    height = height + 1
```

**Does each step climb the same amount, or more each time? Say why.**
