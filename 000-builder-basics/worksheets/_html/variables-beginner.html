🔢 Builder Basics · Variables — English Worksheet (Beginner)

Topic: Variables · Course: Builder Basics · Level: Beginner · Time: about 30 minutes

1 · Predict 🔮

A variable is a name that holds a number. length = 5 means the name length now holds 5.

Read the steps. Circle your answer.

length = 5
repeat length times:
    place block down
    move forward

How many blocks does the agent place? Circle one: 5 · 1 · 10

What does length hold? Circle one: a number · a block · a turn

length = 3
repeat length times:
    place block down
    move forward

How long is the path? Circle one: 3 blocks · 5 blocks · 8 blocks

2 · Find the Difference 🐛

Clean steps first, then a broken version. Circle the bug.

Pair A — The path should be 6 blocks long.

# clean
length = 6
repeat length times:
    place block down
    move forward

# buggy
repeat length times:
    place block down
    move forward
length = 6

What is wrong? Circle one: the number is set too late · the loop is missing · a block is missing

Pair B — The loop should use the name length.

# clean
length = 7
repeat length times:
    place block down
    move forward

# buggy
length = 7
repeat size times:
    place block down
    move forward

What is wrong? Circle one: the name does not match · the number is wrong · the turn is missing
