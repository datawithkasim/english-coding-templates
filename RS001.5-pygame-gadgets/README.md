# 🔧 RS001.5 — 파이게임으로 만드는 진짜 기계 (Python)

안녕하세요, 학부모님! 👋

**영어코딩**의 파이썬 징검다리 과정입니다. 텍스트 어드벤처(RS001)로 변수·리스트·조건문·랜덤을 익힌 학생이, 검은 글자 화면에서 **그림과 버튼이 있는 화면**으로 넘어옵니다. 실제로 쓸 법한 작은 기계 네 대를 직접 만들어요.

**화면을 그리는 어려운 부분은 선생님이 미리 만들어 드립니다.** 창 열기, 버튼 그리기, 클릭 감지 같은 파이게임 뼈대는 시작 템플릿으로 제공되고, 학생은 그 안에서 **파이썬으로 기계가 어떻게 동작할지**를 씁니다. 배우는 것은 파이게임이 아니라 파이썬이에요.

한 주제는 **개념 수업**과 **응용 수업**으로 나눠 다룹니다. 개념 수업에서 새 문법을 배우고, 응용 수업에서 우리 아이만의 버전으로 바꿔요. 진도는 정해진 기간이 아니라 학생 속도에 맞춰 나갑니다.

- **선수 과정**: RS001 텍스트 어드벤처 (변수·리스트·조건문·`random`)
- **다음 과정**: RS002 포켓몬 도감 또는 RS003 파이게임 슈터

---

## 📚 배우는 순서

| 순서 | 만드는 것 | 배우는 것 | 완성하면 이렇게 됩니다 |
|---|---|---|---|
| 1 | ☕ **가상 커피 머신** | 상태를 기억하는 변수, `if`/`elif`로 선택 나누기, 주어진 그리기 함수를 값만 바꿔 호출하기, 좌표 숫자의 의미 | 버튼 세 개(에스프레소·라떼·핫초코)를 클릭하면 컵에 음료가 채워지고 완성 문구가 뜨는 **화면 속 커피 머신** |
| 2 | 🍞 **완벽한 토스트 타이머** | 조금씩 커지는 변수, 비율 계산(퍼센트), 숫자를 색으로 바꾸기, 범위 조건(덜 익음·완벽·탐), 반복되는 코드를 함수로 묶기 | 빵이 점점 갈색으로 변하고, 스페이스바를 누른 타이밍에 따라 판정이 갈리는 **타이밍 게임** |
| 3 | 🔐 **비밀번호 생성기** | 문자 리스트, `random.choice()`, `for` 반복으로 문자열 쌓기, 길이를 바꾸는 변수, 조건으로 규칙 검사(대문자·숫자·기호) | 길이와 문자 종류를 골라 버튼을 누르면 매번 다른 비밀번호가 나오고 **강도 막대**가 함께 뜨는 생성기 |
| 4 | 🕵️ **비밀번호 크래커** | 중첩 반복문, 경우의 수 계산(문자 종류 ^ 길이), 문자열 비교, 시도 횟수 세기, 앞에서 만든 생성기 코드 다시 쓰기 | 자기가 만든 짧은 비밀번호를 컴퓨터가 하나씩 대입해 뚫는 화면 + **"4자리는 몇 초, 12자리는 몇 년"** 비교표 |

> 🧰 프로젝트마다 **시작 템플릿**을 드립니다. 창 열기·버튼 그리기·클릭 감지는 이미 들어 있고, 학생은 "버튼을 누르면 무슨 일이 일어나는가"를 파이썬으로 채웁니다.

> 🔒 마지막 프로젝트는 **학생이 방금 자기가 만든 비밀번호만** 대상으로 합니다. 남의 계정이나 실제 서비스와는 아무 관련이 없고, "왜 복잡한 기호보다 긴 비밀번호가 더 안전한가"를 눈으로 확인하는 보안 수업이에요.

> 💡 프로젝트 4는 프로젝트 3에서 만든 코드를 그대로 가져다 씁니다. 이전 코드는 지우지 말고 남겨 두세요.

- 파이게임 뼈대(창·루프·`draw_button()` 같은 그리기 헬퍼)는 **선생님이 만든 시작 템플릿**으로 제공합니다. 학생이 건드리는 부분은 로직뿐입니다.
