# 📜 RS001 — 텍스트 어드벤처 게임 (Python)

안녕하세요, 학부모님! 👋

**영어코딩**의 첫 파이썬 과정입니다. 한 번에 한 가지 개념만 배우고, 그 개념을 바로 자기 게임에 얹습니다. 처음 만든 코드는 끝까지 버리지 않고 계속 자라나서, 마지막에는 변수·리스트·조건문·함수·랜덤이 한 흐름으로 이어지는 **나만의 텍스트 어드벤처 게임**이 됩니다.

한 주제는 **개념 수업**과 **응용 수업**으로 나눠 다룹니다. 개념 수업에서 새 문법을 배우고, 응용 수업에서 그 문법을 우리 아이 게임에 직접 적용해요. 진도는 정해진 기간이 아니라 학생 속도에 맞춰 나갑니다.
