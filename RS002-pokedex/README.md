# 🔴 RS002 — 포켓몬 도감 앱

안녕하세요, 학부모님! 👋

**영어코딩**의 두 번째 파이썬 과정입니다. 텍스트 어드벤처(RS001)를 마친 학생이 **딕셔너리·함수·다중 파일 구조**를 배우며 포켓몬 도감 앱을 처음부터 끝까지 직접 만듭니다.

한 주제는 **개념 수업**과 **응용 수업**으로 나눠 다룹니다. 개념 수업에서 새 문법을 배우고, 응용 수업에서 그 문법을 우리 아이 앱에 직접 적용해요. 진도는 정해진 기간이 아니라 학생 속도에 맞춰 나갑니다.
